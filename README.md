# codebolt.github.io

This repository is your GitHub Pages user site. Commit Jekyll source files to the repository root and GitHub Pages will publish the site at https://codebolt.github.io.

Quick local steps:
1. Install Ruby and Bundler.
2. Run: `bundle install`
3. Run: `bundle exec jekyll serve`
4. Visit: `http://localhost:4000`

To publish: commit & push to the repository's default branch. Then enable Pages in repository Settings > Pages (branch: main / root).
